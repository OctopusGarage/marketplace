Discover optional avatar, theme, and sticker libraries. Each download is a data-only ZIP pack: images and a manifest, with no executable code. The catalog currently supports Mesh Talk, and its format is open to other apps.

Install in Mesh Talk: Open Settings → Appearance for themes, choose a profile or channel avatar to open the gallery, or open the chat sticker picker and expand Manage sticker packs. You can install a pack directly from the in-app marketplace, or download a ZIP here and choose Install ZIP.
